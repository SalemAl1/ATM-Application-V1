# 🏦 ATM Application (Version 1)

This is my very first team project, built back when my team and I were first learning C++. We didn't know what Object-Oriented Programming was, we didn't know how to organize a codebase.

### 📁 The Anatomy of this horrible thing
If you are looking at the code, here is a quick tour of what you will find:

* **`main.cpp`:** The "Everything Everywhere All At Once" file. All of our procedural logic, PIN verification, and transaction handling is crammed into this single file. There are no classes. There is no encapsulation. It is held together by the power of friendship.
* **`Users Data.cpp`:** A file that is literally just predefined dummy user data sitting inside a giant block comment. Why did I make this a `.cpp` file instead of a simple `.txt` file, an array, or an actual database? Only God knows.

### 🚀 Why is this public?
I am leaving this repository up as a monument to my humble beginnings and as a baseline to document my growth as a developer. 

I am currently actively planning **Version 2**, which will completely refactor this chaotic system into a clean, secure, and professional architecture using strict Object-Oriented Programming (OOP) principles, proper memory management, and actual file separation.
